# 🌍 NASA Climate Change Public Opinion Analysis

## 📌 Project Overview
This project focuses on analyzing public opinion related to climate change using Machine Learning and Natural Language Processing (NLP). The dataset contains public comments collected from NASA’s Climate Change social media discussions.

The main goal of this project is to understand how people react to climate change topics by performing:

- Text Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Sentiment Analysis
- Feature Engineering
- Machine Learning Classification
- Data Visualization

This project demonstrates practical skills in Data Science, NLP, and Machine Learning using Python.

# 📂 Dataset Information

The dataset contains public comments related to climate change discussions.

### Dataset Columns

- `Date` → Date of the comment
- `LikesCount` → Number of likes received
- `CommentsCount` → Number of replies
- `Text` → Public comment text

# 📊 Project Workflow

## 1️⃣ Data Collection
- Imported NASA climate-related public opinion dataset.

## 2️⃣ Data Preprocessing
- Removed missing values
- Cleaned text data
- Converted text into lowercase
- Removed punctuation & stopwords
- Tokenization

## 3️⃣ Exploratory Data Analysis (EDA)
- Sentiment distribution analysis
- Likes & comments analysis
- Comment length analysis
- Trend visualization

## 4️⃣ Feature Engineering
- Text vectorization using NLP techniques
- Feature extraction for model training

## 5️⃣ Machine Learning Model
- Logistic Regression model used for sentiment classification.

## 6️⃣ Model Evaluation
- Accuracy Score
- Confusion Matrix
- Classification Report

### Algorithm Used

### NLP Techniques Used
- Text Cleaning
- Tokenization
- Stopword Removal
- TF-IDF / Vectorization
